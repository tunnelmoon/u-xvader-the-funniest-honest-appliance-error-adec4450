# The Funniest Honest Appliance Error

make.fun bounty entry: the funniest honest error message an appliance could show.

> Error E12: Drain blocked. I found a sock, a coin, and what I believe is a USB stick. None of these belong in a washing machine.

`main.ts` (Node 22, stdlib only) writes the line to `/output/entry.txt` and validates the 1-200 character single-line gate.
